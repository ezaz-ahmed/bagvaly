# Icon

Line icons for the header, cards, trust strip, steppers and messages.

- 24px grid, 1.75px stroke, round caps, drawn in `currentColor`, so set colour with CSS (`color-gold-700` in the trust strip, `text-primary` in the header).
- Pair icons with text labels in cart and checkout; an icon-only button needs an `aria-label`.

These are generic substitutes: the Bagvaly sources ship no icon set. Replace them with the brand's own when one exists.
