# TrustStrip

A thin row of promises under the header or above the footer.

- Ground `bg-muted` (`color-sand-200`); icons in `color-gold-700`; text `text-sm` in `text-primary`.
- Default items: "Cash on delivery" · "Nationwide delivery" · "Easy returns" · "Call or WhatsApp us". It scrolls sideways on small screens and centres from 768px.

The consumer may pass `items` (icon name and label) for Bangla or changed promises.
